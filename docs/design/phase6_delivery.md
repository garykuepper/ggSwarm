## Repository Packaging

### README Structure

The README should allow a new reviewer to reproduce key results in ≤ 30 minutes
without reading any other file:

```
# ggSwarm

## Quick Start
1. Environment setup (conda / Isaac Lab install)
2. Pull a trained checkpoint from GCS
3. Run evaluation: `python scripts/run.py phase3 eval`
4. Run playback:   `python scripts/run.py phase3 play`

## Project Overview
- Problem statement (1 paragraph)
- GNSC 5-layer architecture (link to docs/design/architecture.md)
- Key results table (formation error, collision rate, recovery latency)

## Training From Scratch
- Phase 2: `python scripts/run.py phase2 train --headless`
- Phase 3–4: config flags in drone_swarm_env_cfg.py
- Full pipeline: see docs/ops/training_workflow.md

## Results
- Link to demo video
- Link to Testing Report (docs/testing_report.md)
- TensorBoard screenshot of converged training curve
```

### Reproducibility Verification

Before tagging `v1.0.0-capstone`, verify the following on a clean Python environment:

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Pull the final checkpoint
python scripts/cloud/pull_results_from_gcs.py --family marl --latest 1

# 3. Run unit tests (should pass in < 10 s)
pytest tests/unit/ -q

# 4. Run evaluation (Phase 3 nominal)
python scripts/run.py phase3 eval --num_episodes 5

# 5. Run playback (requires Isaac Sim)
python scripts/run.py phase3 play --checkpoint <path>
```

All five steps must complete without errors. Results from step 4 must match the
Testing Report table within ±5%.

## Presentation Guide

### Poster / Slide Deck Structure (10 slides)

1. **Title** — project name, student, advisors, date
2. **Problem** — centralized vs. decentralized failure modes; swarm scale challenge
3. **GNSC Architecture** — 5-layer diagram from `architecture.md`
4. **Phase 1–2: Foundation + Brain** — simulation setup, GATv2 policy, convergence curve
5. **Phase 3: Muscle Refinement** — CBF math, SwarmRaft consensus, MINCO EMA diagram
6. **Phase 4: Stress Testing** — scenario matrix, 100-episode metrics table
7. **Phase 5: Showcase** — cluttered forest screenshot; demo video QR code
8. **Results vs. Proposal Objectives** — O1–O4 pass/fail table
9. **Lessons Learned** — what worked, what didn't, what would be different
10. **Future Work** — true MINCO polynomial, real hardware transfer, ROS 2 bridge

### Live Demo Script (if Isaac Sim available)

1. Start `phase3 play` with the cluttered forest config.
2. Point out formation keeping in nominal flight (30 s).
3. Trigger agent loss via keyboard shortcut (if wired up) or start a pre-configured `agent_loss_enabled=True` episode.
4. Show SwarmRaft gap-fill on screen.
5. Highlight CBF activation indicators if logged.
