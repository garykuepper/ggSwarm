# Phase 14a: Part 107 Remote Pilot Certificate

**Status:** Planned. First Phase 14 sub-phase. Personal certification gate
for everything downstream.

**New capability:** legal authorization to fly small UAS commercially in
the U.S. National Airspace System.

## Scope

1. **Study + pass the FAA Part 107 Remote Pilot Knowledge Test.**
   Recognized study materials (commercial study apps, FAA's official
   study guide). Cost ~$175 plus study time.
2. **Schedule + take the test** at an FAA-authorized testing center.
3. **Complete IACRA application** to receive the temporary certificate;
   physical certificate follows.
4. **TRUST certificate** for recreational background context (lower
   priority; complete if not already held).

## Inputs from prior phase

- None — personal certification, decoupled from Phase 13 hardware progress.
  Can be pursued in parallel with hardware-block work as soon as the
  decision is made to commit to Phase 14.

## Methodology

- Personal study schedule documented in repo private notes (not in this
  doc — keep certification details to status updates).
- Practice tests until consistent ≥ 90% score before scheduling the real
  test.
- Test scheduling: at an FAA-authorized testing center within driving
  range; window measured in days, not weeks.

## Milestone artifact

Part 107 Remote Pilot Certificate (digital + physical). IACRA application
record. `status/changelog.md` entry recording the date.

## Scorecard schema

| Metric | Target |
| :--- | :--- |
| Practice-test consistency before real test | ≥ 90% |
| Real-test pass on first attempt | True (re-take fee + delay otherwise) |
| Time from study start to certificate | ≤ 2 months |

## FAA evidence produced

The certificate itself is the legal foundation that makes every
subsequent Phase 14 sub-phase possible. No safety-case data, but a
program-level prerequisite gate.

## Risks

- Fail real test → re-take after waiting period; absorbs schedule time.
  Mitigation: high practice-test consistency bar before scheduling.
- Knowledge-area weakness (airspace classes, weather, sectional charts) →
  targeted review before test.

## Decline list

- **Recreational-only path** — declined; recreational rules
  (FAA recreational exception + TRUST) do not authorize the paid flying
  Phase 14d targets.
- **Skipping the cert and operating informally** — declined; FAA
  enforcement risk; insurance gap; reputational cost; ineligible for
  § 107.35 waiver.
