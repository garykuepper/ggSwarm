# Archive

The original ggSwarm Live plan (2026-04-30 through 2026-07-03): an
18-phase structure covering sim decentralization, downwash, shape
libraries, animated formations, outdoor/obstacle work, onboard
distillation, multi-platform domain randomization, a strict hardware
bring-up sequence, and a Skybrush-choreography drone-show milestone
with its own regulatory sub-phases.

Simplified on 2026-07-03 to two active phases
([Phase 1: Sim](../phases/phase1_sim.md),
[Phase 2: Hardware](../phases/phase2_hardware.md)) plus an unordered
[backlog](../backlog.md). Nothing here is deleted — it's design detail
kept for reference in case any of it turns out useful again, and it's
the reference the (now separate) drone-light-show project can start
from if it wants the old Skybrush/RL-overlay architecture.

- `vision_v0.2.md` — the full 18-phase FR/NFR plan
- `architecture.md` — Skybrush + PX4 RL-waypoint-overlay architecture
- `consensus_mechanisms.md` — decentralization mechanism rationale (why
  auction/gossip/CRDT, not blockchain or Raft) — directly relevant
  background for the active Phase 1 decentralization goal
- `backlog_detailed.md` — the original effort/impact-scored backlog,
  with full design detail per item (Bertsekas auction, versioned
  gossip/CRDT, residual-test fault detection, glyph-to-points, etc.)
- `phases/` — all superseded phase docs: the sub-phased decentralization
  stack (2, 2a–2d), sim capability phases (3–9), the strict hardware
  bring-up sequence (10–13), the drone-show milestone and its
  regulatory sub-phases (14, 14a–14d), and post-show vision phases
  (15–18)
